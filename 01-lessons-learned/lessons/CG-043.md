# CG-043 — Guided-demo tests must traverse the journey and assert expected state

- **Date discovered:** 2026-11-25

- **Severity and rationale:** Medium — a route-only smoke test can pass while the intended user journey, data relationships or safety states are broken.
- **Applicability:** General

## Event
The Guided Demo Journey was strengthened from merely checking destination-page responses to opening the journey from the workspace hub, clicking through its six declared destinations and checking the expected fictional player, opportunity and request relationships and safety states.

The ScoutSA prototype README records 9/9 Guided Demo Journey groups passing in hosted workflow #1087 at the exact documentation-inclusive head above.

## Expected behaviour
Acceptance evidence should exercise the journey a user actually follows and assert the important content, relationships, decisions and blocked states—not merely that each destination returns successfully.

## Actual behaviour
The exact-head record states that the browser test checks the same fictional player reference, the matching opportunity and request, blocked guardian-consent/disclosure, matching pairs remaining on hold, a non-submittable discovery request, and the absence of an invented trial or placement outcome.

## Impact
A route-only check can provide false confidence: pages may load while the intended workflow is disconnected or displays unsafe or incorrect state.

## Root cause
Test-scope weakness identified during prototype acceptance review. This lesson records the test-design correction; it does not claim a production defect.

## Corrective action
Use a browser-level journey test that starts at the hub, traverses each declared step and asserts the expected fictional state and safety constraints at each material boundary.

## Preventive / detective control
For each guided workflow, define a small acceptance matrix mapping: user action → destination → expected entity/state → prohibited state → observable assertion. Keep route availability checks as a separate, weaker signal.
