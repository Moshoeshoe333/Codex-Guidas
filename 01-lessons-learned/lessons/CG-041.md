# CG-041 — Independent regression suites should continue after one suite fails, while preserving a failing aggregate result and per-suite diagnostics.

**Source / origin:** ScoutSA OPA-019

**Evidence class (preserved):** Derived; workflow mitigation committed, exact-head execution pending

**Lesson status:** Derived

## Reusable control

Use bounded loops or matrices, cap each process and the overall job, report every suite outcome, and never convert partial success into a green aggregate.
