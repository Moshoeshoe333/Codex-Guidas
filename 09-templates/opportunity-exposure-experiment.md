**Purpose:** Test one bounded idea for increasing exposure to relevant opportunities without confusing attention, visibility, access, trust or outcomes.

> Increase the quality of relevant encounters. Do not inflate activity, risk, or claims.

This template is informed by the external *Luck Field Manual* field note. It is not a scientific instrument, a prediction model, an audit certification or a promise of success. Use the template to test a local hypothesis only.

## C. Define the opportunity funnel before acting

Use only the stages relevant to the experiment. Define each stage operationally before collecting data.

| Stage | Working definition | Count / denominator | Evidence source |
|---|---|---|---|
| Relevant exposure | A person or organisation in the defined target group actually encounters the work, profile or request | | |
| Qualified signal | A specific response indicating relevance or a genuine problem/interest, not a view or generic like | | |
| Access | A concrete next step becomes available, such as an interview, meeting, user task, demo or formal application route | | |
| Trust / readiness | The other party has sufficient reason and evidence to proceed, with expectations and constraints made clear | | |
| Outcome | The intended result occurs: completed task, interview, pilot, contract, placement, repeat use, payment or other defined endpoint | | |

**Critical distinctions:** Exposure is not an opportunity. A qualified signal is not access. Access is not trust. Contact is not an outcome. Report each stage separately; never collapse the funnel into a single "success" number.

## Interpretation guardrails

1. More attempts are useful only when they are relevant, ethical and informative.
2. Better discoverability may create more qualified encounters; it does not guarantee access.
3. Credible work and trustworthy conduct matter more than raw attention.
4. Relationships are reciprocal, not merely channels to exploit.
5. Preserve downside protection, personal safety, privacy and time for core work.
6. Persist intelligently; stop when the evidence or cost warrants it.
7. Treat this as a local experiment record, not validation of the complete external manual.
